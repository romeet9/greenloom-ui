# Green Loom AI — UI Design System

> Enterprise-Grade UI System & Component Foundation for Green Loom AI Applications.

Built with React, Tailwind token architecture, **Geist & Geist Mono** typography, and a custom **Powder Green** aesthetic.

---

## 📦 Packages

```bash
# Install core components and tokens
npm install @greenloom/ui
```

---

## 🌿 Core Stack & Features

- **Typography:** Geist for interface text & Geist Mono for tabular numerical data.
- **Brand Tokens:** Powder Green (`#c7fbab` / `#8db279`), Neutral Black & Light, Powder Accents.
- **Icons:** Standard 24x24 stroke Hugeicons & custom Green Loom AI glyphs.
- **Components:** 80+ enterprise-grade primitives including Data Tables, Modals, Forms, Navigation, Badges, and Metrics.
- **Theme Modes:** Verified WCAG AAA contrast across both Light and Dark mode.

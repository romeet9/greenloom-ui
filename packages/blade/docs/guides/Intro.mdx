## What is Loom UI?

Loom UI is the accessible, cross-platform design system engineered for Green Loom web and mobile products. It provides battle-tested UI primitives, layout utilities, and high-density components optimized for enterprise workflows.

## Features

- **Dense Data Ergonomics**: Built for complex financial reconciliation, dense tables, multi-tier filters, and enterprise dashboards.
- **Strict Accessibility (WCAG AAA)**: Zero automated a11y violations, full keyboard navigation, and high-contrast dark surfaces (`#0D1117`).
- **Powder Green Standard**: Balanced, natural color token system paired with Geist typography scales.
- **AI-Native Pair Programming**: Official `@greenloom/mcp` Model Context Protocol server for Claude Code and Cursor integration.
- **Cross-Platform**: Unified component APIs across React Web and React Native.

## Packages

```shell
@greenloom/ui/components   # 80+ Accessible UI primitives & layout composites
@greenloom/ui/tokens       # Powder Green palette, Geist typography, Spacing & Motion tokens
@greenloom/ui/utils        # Theme provider, accessibility helpers & responsive breakpoints
@greenloom/mcp             # Model Context Protocol server for AI assistant pair-programming
```

## Quick Start

### 1. Install Dependencies

```shell
yarn add @greenloom/ui styled-components@5.3.11 @hugeicons/react framer-motion@11.13.3
```

### 2. Wrap your Application

```tsx
import React from 'react';
import { BladeProvider, Button, Box, Heading } from '@greenloom/ui/components';
import { bladeTheme } from '@greenloom/ui/tokens';

export function App() {
  return (
    <BladeProvider themeTokens={bladeTheme} colorScheme="dark">
      <Box padding="spacing.6">
        <Heading size="large">Welcome to Green Loom</Heading>
        <Button variant="primary" marginTop="spacing.4">
          Get Started
        </Button>
      </Box>
    </BladeProvider>
  );
}
```

Loom UI is the open-source design system powering **Green Loom**. We welcome contributions from engineering teams across all products and external contributors.

---

## Local Development Workflow

1. **Install Dependencies:**
   ```bash
   yarn install
   ```

2. **Start Storybook Server:**
   ```bash
   yarn react:storybook
   ```

3. **Typecheck & Validation:**
   ```bash
   yarn typecheck
   ```

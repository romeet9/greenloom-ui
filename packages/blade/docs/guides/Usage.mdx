## 1. Wrap Your App with `BladeProvider`

To activate theme tokens, responsive breakpoints, and dark mode transitions, wrap your application root inside `BladeProvider`:

```tsx
import React from 'react';
import { BladeProvider } from '@greenloom/ui/components';
import { bladeTheme } from '@greenloom/ui/tokens';
import App from './App';

export default function AppWrapper(): JSX.Element {
  return (
    <BladeProvider themeTokens={bladeTheme} colorScheme="dark">
      <App />
    </BladeProvider>
  );
}
```

### Benefits of the Loom Provider:
* **Responsive Breakpoints:** Components adapt automatically across mobile ($375\text{px}$), tablet ($768\text{px}$), and desktop ($1024\text{px}+$).
* **Instant Dark/Light Theming:** Seamless switching between high-contrast dark mode and clean light surfaces.
* **Typographic Standardization:** Automatic rem/px calculations mapped to the **Geist & Geist Mono** scales.

## 2. Consuming Components

Import UI components, icons, and tokens directly from `@greenloom/ui`:

```tsx
import { Button, SideNav, DownloadIcon } from '@greenloom/ui/components';

export function ExportAction() {
  return (
    <Button 
      variant="secondary" 
      size="medium" 
      icon={DownloadIcon} 
      iconPosition="left"
      accessibilityLabel="Export report"
    >
      Export Report
    </Button>
  );
}
```

## 3. Mapping Tokens from Figma to Code

Loom UI is designed with a **"What you see in Figma is what you get in Code"** standard.

> **Important Rule:** Never hardcode hex/RGB values. Always use semantic token paths (`surface.background.gray.moderate`, `surface.text.gray.normal`) so your UI automatically adapts to dark mode.

```tsx
import styled from 'styled-components';
import type { Theme } from '@greenloom/ui/components';

const StyledCard = styled.div(
  ({ theme }: { theme: Theme }) => `
    width: 368px;
    background-color: ${theme.colors.surface.background.gray.moderate};
    border: 1px solid ${theme.colors.surface.border.gray.subtle};
    padding: ${theme.spacing[5]}px;
    border-radius: ${theme.border.radius.medium}px;
  `
);
```

## 4. Mobile & iOS Safari Optimization

When using overlay components like `BottomSheet` or `SpotlightPopoverTour` on mobile Safari, ensure your global stylesheet contains:

```css
html, body {
  width: 100%;
  height: 100%;
  -webkit-overflow-scrolling: touch;
}
```
